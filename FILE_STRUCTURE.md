## 🗄️ Database Schema Diagram

```
Category (table: shop_category)
├── id (PK)
├── name
├── slug (unique)
├── description
├── image (FK: media)
├── created_at
└── updated_at
    │
    └─→ [1-to-Many] Product

Product (table: shop_product)
├── id (PK)
├── name
├── slug (unique)
├── category_id (FK)
├── description
├── short_description
├── price
├── old_price
├── image (FK: media)
├── gallery_images (JSON)
├── available_sizes (JSON)
├── stock_quantity
├── is_featured
├── is_active
├── created_at
└── updated_at
    │
    └─→ [1-to-Many] CartItem

User (table: auth_user) ← Django's built-in
├── id (PK)
├── username
├── email
├── password
└── ...
    │
    └─→ [1-to-1] Cart

Cart (table: shop_cart)
├── id (PK)
├── user_id (FK) [one-to-one]
├── created_at
└── updated_at
    │
    └─→ [1-to-Many] CartItem

CartItem (table: shop_cartitem)
├── id (PK)
├── cart_id (FK)
├── product_id (FK)
├── quantity
├── size
└── added_at
```
